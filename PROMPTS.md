# HemoPulse AI — Prompt Engineering Log (PromptWars Ranchi)

## Stage 1: Product Requirements Document (PRD) Generation
> **Goal:** Translate the raw healthcare problem statement into a structured MVP architecture, user flow, and technical specification before generating code.

**Prompt:**
"I am participating in a 1-day AI hackathon and received this problem statement: [Predictive Blood Shortage & Hospital Coordination Network]. My goal is to build the highest-impact, most polished, and winning prototype possible within 5-6 hours using AI coding tools. Act as a Principal Product Manager and Lead AI Architect, and write a comprehensive, structured Product Requirements Document (PRD) including App Name, Value Proposition, Core Features, User Journey, Optimal Tech Stack, and a Complete Master Prompt."

## Stage 2: Full-Stack Command Center Generation (Master Prompt)
> **Goal:** Generate a complete, interactive React + TypeScript + Recharts dashboard with FEFO matching, 7-day predictive analytics, and live crisis simulation.

**Prompt:**
"Build a complete, production-grade web application called 'HemoPulse AI' — an AI-powered predictive blood shortage network and regional hospital coordination platform using React, TypeScript, Tailwind CSS, Recharts, and Lucide-react icons. Include: (1) Executive Command Dashboard with KPIs, interactive SVG Regional Geo-Map, and 7-day supply vs. demand forecast chart; (2) AI Shortage Prediction & Smart FEFO Matching Engine with 1-click dispatch; (3) Expiry-Aware Inventory Matrix; (4) Interactive 'Simulate Crisis Surge' demo presets; and (5) AI Tactical Executive Briefing Panel."

> **Goal:** Ground the network in real-world Ranchi healthcare infrastructure and add a live conversational AI Copilot drawer.

**Prompt:**
"Keep all existing layout, styling, charts, and features intact, and apply these two upgrades: (1) Localize the entire regional network to Ranchi, Jharkhand (RIMS Ranchi, Medica Superspecialty Hospital, Raj Hospital, Orchid Medical Centre, Sadar Hospital Blood Bank, and Jharkhand Red Cross Hub) with realistic distances/ETAs and local crisis presets (NH-33 Highway Mass Trauma, Post-Monsoon Ranchi Dengue Surge); (2) Add a floating 'Ask HemoPulse AI' button opening a slide-over AI Copilot drawer with one-click starter questions that generate data-backed answers from live inventory."
